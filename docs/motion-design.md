# 视觉与交互实现

2026-11-05。采用 finesse-ui 的视觉编排规则与 motion-web 的动作分工、真实输入和静止画面检查。用户提供的 DESGINS.md 明确要求浅色展厅与单一蓝色操作色，因此保留该方向，不套用技能通用的深色背景和颗粒纹理。

## 视觉

基础画布 #fbfbfd / #f5f5f7，文字 #1d1d1f，交互色 #0066cc。中文使用本地 Noto Sans SC 子集，主要字重 400–650。作品墙、创作记录及档案弹窗使用直角和开放版面；分隔线组织信息，不设置独立卡片底色与阴影。首屏画廊保留原有插画叠放。插画有独立的画面色彩，不改变界面的操作色。

作品墙以项目封面、名称和过程缩略图表达入口，已删除重复的宣传语和次要标签。保留一处主品牌主题和必要的服务说明。作品封面是本地原创占位插画，所有详情演示与过程记录都是视觉样例。

## 动作分工

| 区域       | 行为                                                                            | 实现                                                                    |
| ---------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 首屏画廊   | 随指针轻微转动，侧卡、圆点、箭头和拖动切换                                      | Motion spring / pan；禁止浏览器原生图片拖拽，避免抢占手势               |
| 课程 SOP   | 左侧目录切换右侧记录照片/截图与说明，图片打开多图创作档案；六维总览保持独立静态 | Motion layout 标记滑移、CSS 图片缩放过渡、原生 dialog；媒体偏好实时降级 |
| 作品墙     | 搜索和分类后档案横列保留身份并重排，记录缩略图始终可见                          | Motion layout + 160ms opacity / 240ms y                                 |
| 弹窗       | 轻微放大进入，Escape / 关闭按钮 / 遮罩可退出，恢复焦点                          | 原生 dialog 与 CSS                                                      |
| 方案与预约 | 档位更新价格、说明和咨询上下文；预览返回保留输入                                | React 本地状态，无网络提交                                              |

交互不劫持滚轮，无自动播放、无连续后台渲染。指针动作仅在细指针设备启用。图示的配色、轨道与票券用于支持内容，没有新增装饰性漂浮粒子。

## 手机与减少动态效果

手机保留滑动和点击入口；首屏按钮、画廊控制、分类、方案切换与弹窗均可键盘操作。作品墙在桌面将作品与关键记录并列，在手机上将记录图片排在项目身份下方；窄平板课程页将体验放在上方，两种后续服务并排。

首页第二部分为左侧纵向创作目录、右侧记录图片与一张完整六维总览的开放版面；没有卡片底色、圆角或阴影。手机端目录分为五列两行，图片和总览随后纵向展示。十个节点代表项目创作记录，不对应固定授课次数。雷达图六个轴均有示意顶点，整张多边形在切换记录时保持不变；显示明确注明为示例的六个数值，满量程为 10；不是测评方法或真实学员数据。文字与雷达形状均为视觉占位；记录图片为按用户要求下载的对标站参考素材，已标明来源。首页不再重复展示“作品精选”。

系统请求减少动态效果时，关闭 CSS 动画、滚动变化和指针倾斜，Motion 直接切换至目标状态。静止画面仍包含全部内容与入口。

验收执行真实鼠标移动、拖动、滚轮、点击和键盘操作，不仅检查组件内部状态。性能数据若有，均为本机浏览器测量，不代表真实中端手机。

## 创作档案交互

记录时间线是共用基线上的图片序列，使用原生横向滚动和吸附定位，保留首尾按钮及键盘访问。点击每次记录打开完整档案：桌面左图右文，手机先显示记录标题，再看图片和观察。图片缩略图通过点击或左右方向键切换；切换记录重置图库，前后按钮保留焦点。没有自动翻页。

项目总览中的六个维度均有数值和多边形顶点。选择维度时只更新观察与对应记录入口，图形保持整个项目的总览，不随单条记录改变。图片切换使用轻微水平位移，维度内容独立过渡；系统减少动态效果时直接呈现最终状态。

记录弹窗使用原生 dialog、Tab 边界循环与 Escape 关闭。直接记录链接在浏览器完成首屏接管后打开，避免预渲染差异；打开和关闭保持原页面锚点，支持浏览器前进后退与焦点恢复。
